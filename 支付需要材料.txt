 一、开工必需资料

  - [ ] 目标用户地区：中国大陆 / 海外 / 两者     最好是面向全球用户的
  - [ ] 收款渠道：微信支付 / 支付宝 / Stripe   无论支付宝微信还是stripe,都只能固定金额收款，
  - [ ] 经营主体：个人、个体户或公司名称  经营主体这三个都有的。
  - [ ] 商户账号申请状态：未申请 / 审核中 / 已开通   我认为支付宝微信采用固定二维码收款，尽量避免调用接口吧，当然如果需要网站支付，也是可以的。
  - [ ] 产品域名，以及是否能操作 DNS      产品域名都有的。
  - [ ] 部署平台：现有服务器、Render、阿里云、腾讯云等   服务器阿里云2H4g，腾讯云4H4g，海外服务器比较小。
  - [ ] 邮件服务商：阿里云邮件推送、腾讯云 SES、Resend 等    邮件服务商，不是可以用goole的吗，或者supebase是不是也有邮箱注册相关的。
  - [ ] 发信域名、发件人名称、发件邮箱    这个我不知道，
  - [ ] 中转上游名称、接口地址、支持模型、成本价    上游中转我决定采用自有的codex中转，大概是5块钱100刀的倍率。
  - [ ] 上游是否书面允许商业使用及额度转售  自己搭建的

  二、价格与额度规则

  - [ ] 币种：人民币或美元   国内用人民币，国外有美元，
  - [ ] 额度包，例如 ¥20 / ¥50 / ¥100   这种也是合适的，国内的中转站都是这个样子的，
  - [ ] 每个额度包实际获得多少网关余额  这个倍率的计算不知道，最后定也来得及
  - [ ] 售价与美元模型成本之间的换算规则  按真实汇率或者1：7固定
  - [ ] 是否赠送注册体验额度，以及金额    不赠送
  - [ ] 额度是否过期     不过期
  - [ ] 最低充值金额10块钱或者1 刀吧1刀等于7 块人民币
  - [ ] 是否允许余额为负   不允许
  - [ ] 退款规则：未使用可退、按比例退或不退款    做这个是一个扯皮的，原则是不允许
  - [ ] 是否需要开票  没有票可以开的
  - [ ] 首版是否只做预付费，建议暂不做月订阅    按照额度来，不做订阅，
 
  三、注册与账号规则

  - [ ] 登录方式：邮箱验证码或 magic link，建议验证码    邮箱验证码
  - [ ] 注册时收集哪些字段，建议首版只收邮箱   邮箱就好了
  - [ ] 一个邮箱是否只对应一个 tenant   我不清楚
  - [ ] 是否允许一个账号创建多个 API Key   要那么多key干嘛呀
  - [ ] 新 Key 是否设置默认有效期，建议 90 天   按这个也可以
  - [ ] Pacer 登录方式：浏览器授权还是手工粘贴 Key，建议浏览器授权    授权登录吧
  - [ ] 登录会话有效期，例如 30 天 可以的
  - [ ] 是否允许用户注销账号、导出账单   可以的
  - [ ] 是否限制一次性邮箱或高风险地区   我不知道

  四、支付接入资料

  微信支付需要准备：

  - [ ] 微信支付商户号 mchid
  - [ ] 关联公众号、小程序或开放平台 appid
  - [ ] API v3 Key
  - [ ] 商户证书序列号及私钥
  - [ ] 支付回调域名
  - [ ] Native 扫码支付权限，适合桌面端 Pacer 用户

  支付宝需要准备：

  - [ ] 支付宝应用 app_id
  - [ ] 应用私钥及支付宝公钥或证书
  - [ ] 电脑网站支付产品权限
  - [ ] 支付回调域名
  - [ ] 沙箱账号

  Stripe 需要准备：

  - [ ] Stripe 商户账号
  - [ ] Publishable Key
  - [ ] Secret Key
  - [ ] Webhook Signing Secret
  - [ ] 结算币种与账单描述

  实际开发前只需确认渠道和账号状态，密钥在接入阶段通过 Secret 配置。

  五、邮件资料

  - [ ] 邮件服务商账号
  - [ ] API Key 或 SMTP 凭据
  - [ ] 发信域名 DNS 操作权限
  - [ ] SPF、DKIM、DMARC 配置权限
  - [ ] 验证码有效时间，建议 10 分钟
  - [ ] 验证码邮件文案
  - [ ] 登录提醒邮件文案
  - [ ] 客服邮箱
  - [ ] 邮件发送频率限制，例如每邮箱每分钟一次

  六、品牌与页面资料

  - [ ] 正式产品名：Pacer 或其他名称
  - [ ] Logo、图标和品牌色
  - [ ] 网站标题与一句话介绍
  - [ ] 购买页套餐说明
  - [ ] 客服联系方式
  - [ ] 用户协议
  - [ ] 隐私政策
  - [ ] 充值与退款规则
  - [ ] 公司名称、地址和备案信息
  - [ ] 是否需要中文、英文双语

  七、运维与风控

  - [ ] 管理员邮箱
  - [ ] 支付异常告警接收渠道
  - [ ] 低余额和上游故障告警阈值
  - [ ] 数据库备份位置及保留时间
  - [ ] 用户余额人工调整权限由谁持有
  - [ ] 可疑注册、盗刷和 API 滥用处理规则
  - [ ] 单用户 RPM、并发数和每日消费上限
  - [ ] 上游不可用时是否自动切换线路
  - [ ] 客服响应时间和退款处理人
