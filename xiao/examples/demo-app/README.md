# Demo App

This is a minimal Vue 3 + Vite application used as a Checkpoint practice target.

## Run

```powershell
npm install
npm run dev
```

The app runs on `http://localhost:4173` by default.

## Workflow suite

- `workflows/home_smoke.yaml`
- `workflows/login_smoke.yaml`
- `workflows/login_regression.yaml`
- `workflows/list_smoke.yaml`
- `workflows/list_regression.yaml`
- `workflows/form_smoke.yaml`
- `workflows/form_regression.yaml`

Use `visual-agent workflow-lint` on each workflow before sharing it.
